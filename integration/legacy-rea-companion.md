## Reconstruction companion

When using REA to understand a target for reconstruction, plan a similar
implementation, or rebuild selected functionality, also load the installed
`rea-reconstruction-companion` skill through the current skill catalog if it is
not already loaded. Apply both throughout the task, sharing one resolved brief,
question checklist, and evidence ledger. REA governs target routing, tool use,
evidence handling, and runtime boundaries; the companion guides requirements,
design, implementation, optimization, and validation within the user's scope.

Use findings to refine the specification and return to focused REA analysis
when planning, implementation, or testing exposes an evidence gap. Reconcile
new findings with affected requirements, design choices, and tests. Loading the
companion continues the same investigation; do not recursively reload either
skill or repeat matching analysis.

Keep the combined workflow proportional to the requested target and objective.
Narrow explanations, comparisons, and diagnostics can use REA alone unless the
user also requests reconstruction work. If the companion is unavailable, report
that limitation and continue supported REA work without installing it implicitly.
